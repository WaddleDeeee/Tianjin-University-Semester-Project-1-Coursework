# BCI EEG Signal Processing

Small Python project for plotting EEG signals, event-related responses, and power spectra from BCI Competition IV 2a recordings in `archive/`.

- `main.py`: read and inspect the signal data.
- `eeg_erp_plot.py`: event-related potential plot.
- `eeg_power_spectrum.py`: power-spectrum plot.
- `outputs/`: generated figures.
- `assignment_figures/`: copies of selected figures.

Run the scripts with Python 3 and their imported scientific packages (NumPy, SciPy, MNE, matplotlib). Check the script arguments and input paths before running on another computer.
